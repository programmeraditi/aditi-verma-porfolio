# Aditi Verma — React Portfolio

This portfolio is built with React and Vite. Its original content, responsive styling,
links, and interactions are retained.

## Run locally

1. Install [Node.js](https://nodejs.org/).
2. From this folder, install dependencies:

   ```sh
   npm install
   ```

3. Start the development server:

   ```sh
   npm run dev
   ```

4. Open the local URL printed by Vite.

## Available scripts

- `npm run dev` — start the local development server.
- `npm run build` — create a production build in `dist/`.
- `npm run preview` — preview the production build locally.

Google Fonts are loaded online; the layout and React icons are bundled with the project.
